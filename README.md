# さわる数学

「さわる数学」は、数学の概念を、図を動かしたり、数値を変えたり、問題に挑戦したりしながら学ぶためのインタラクティブ教材集です。

「計算できた」「正解した」で終わらず、なぜそうなるのかを、図・言葉・数式を結びつけて理解できる教材を目指しています。

## 現在の教材

### 確率・統計

- [2次元正規分布をさわる](bivariate_normal_3d.html) — 期待値・分散・相関係数を動かし、確率密度の3D曲面と分散共分散行列の変化を確認できます。

### 極限・連続性

- [ε–δチャレンジ](epsilon_delta_challenge.html) — コンピュータが指定する ε に対して δ を選び、連続性の条件を満たせるか挑戦する教材です。全6問から問題を選べます。
  - グラフの拡大・縮小と、ε・δの範囲に合わせた表示
  - 連続な関数と、不連続な関数の比較
  - 条件が成り立つ理由や、反例が見つかる理由の解説
  - 同じ ε での再挑戦

### 積分

- [リーマン積分をつくる](riemann_integral.html) — 分割と代表点を動かし、リーマン和・上和・下和から積分の定義を理解する教材です。
  - 等分割・不等分割と、左端・中央・右端・ランダムな代表点の比較
  - 上和と下和の差による、代表点の選び方によらない誤差の確認
  - 連続関数、不連続でも積分できる関数、積分できない関数の全6例
  - リーマン積分の定義と、任意の誤差に対して成り立つ理由の解説

## 使い方

このリポジトリをダウンロードまたはクローンし、教材の HTML ファイルをブラウザで開いてください。現在の教材は、インストールやビルドをせずに利用できます。

## 今後の予定

今後は分野ごとに教材を増やし、探しやすい形に整理していく予定です。

- **極限・連続性**：極限の定義、連続と不連続など
- **微分**：微分係数、接線、関数の変化など
- **積分**：面積、リーマン和、微分と積分の関係など
- **複素関数論**：複素平面、複素関数による写像、複素積分など

上記は制作予定の例です。扱う分野やテーマは順次追加していきます。

## 教材づくりの方針

- 自分で操作し、予想を立てて確かめられること。
- 図による直感と、定義や数式による説明をつなぐこと。
- 成功例だけでなく、反例や条件を満たさない場合も扱うこと。
- 正誤だけでなく、「なぜそうなるのか」を丁寧に説明すること。
