Church numeral：数は「何回使うか」で表す

Church numeralのnは，関数fと値xを受け取り，fをxにn回適用するλ式です．数字を格納する箱を使わず，関数だけで自然数を表します．

0 = λf. λx. x
1 = λf. λx. f x
2 = λf. λx. f (f x)
3 = λf. λx. f (f (f x))

ADD 2 3 を最後まで簡約すると，fを5回適用する式になります．結果の数は，得られたλ式の形から読み取っています．

FALSE = λa. λb. b はChurch numeralの0と，束縛変数の名前を除けば同じ式です．同じλ式を，数としても真偽値としても解釈できます．

β簡約：関数へ引数を渡す

(λx. M) N → M[x := N]

関数の本体Mの中で，自由に現れるxを引数Nに置き換えます．オレンジで囲んだ部分が次に書き換える場所です．

(λx. x) a → a

α変換：変数の捕獲を避ける

(λx. λy. x) y を λy. y にしてしまうと，自由だったyが束縛され，意味が変わります．先に内側のyを改名します．

(λx. λy. x) y →α (λx. λy1. x) y →β λy1. y

この教材では，必要なα変換を独立した1ステップとして表示します．η簡約は行いません．

順序によって，終わり方が変わる

(λx. a) OMEGA を試してみましょう．正規順序なら外側を先に簡約してaになります．適用順序なら，先に引数OMEGAの簡約を続けてしまいます．

OMEGA = (λx. x x) (λx. x x)

OMEGAは1回β簡約すると同じ式へ戻ります．同じ式の再出現を検出すると自動再生を一時停止しますが，簡約はまだ可能です．

「正規形」は，β簡約する場所も，展開する略記も残っていない式です．自由変数がある式も正規形になれます．

正規順序では，正規形が存在するならそこへ到達できます．ただし，この教材では表示する式の大きさと自動再生の連続ステップ数に上限を設けています．
